# Maricones Awards
Esta pagina web es un cuestionario para ver quien se lleva el premio a el más gracioso, a el más divertido..etc.
La pagina web permite seleccionar quien eres de entre mi grupo de amigos y una contraseña para contestar a un cuestionario sobre quien crees que merece tener el premio, cada uno tiene su contraseña personal para no dejar que se suplanten la identidad entre ellos.

Las respuestas se me envian a un documento Excel como Base de Datos y luego se lo pasaré a la IA para que establezca opiniones y puntuaciones y decida el podio.
